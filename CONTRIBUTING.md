# Contributing / المساهمة

Thank you for improving Archive Explorer. Use Go 1.22+, keep the project dependency-light, run `gofmt -w .`, `go vet ./...`, and `go test ./... -race` before submitting changes. Security-sensitive archive parsing or extraction changes must include regression tests. Keep behavior cross-platform and document user-visible changes.

شكرًا للمساهمة. استخدم Go 1.22 أو أحدث، وحافظ على بساطة الاعتماديات، وشغّل التنسيق والفحص والاختبارات قبل إرسال التغييرات. أي تعديل يمس تحليل الأرشيف أو الاستخراج الآمن يجب أن يتضمن اختبارًا يمنع عودة المشكلة، مع الحفاظ على التوافق بين الأنظمة وتوثيق التغييرات الظاهرة للمستخدم.
